## 🔎 Why these JavaScript challenges matter

These problems strengthen practical skills across asynchronous JavaScript, promises, polyfills, functional patterns (debounce, throttle, currying, composition), data structures (LRU cache), parsing, and API performance techniques (caching, retries, circuit breaker). They are ideal for interview prep, daily practice, and building a strong foundation for front-end architecture.

### Key topics covered

- Asynchronous control flow: `fetch` timeout, retries with backoff, circuit breaker
- Promise utilities: `Promise.all` polyfill, promisify, sequential queues
- Functional utilities: debounce, throttle, memoization, currying, piping/composition
- Data structures & algorithms: LRU cache, flatten object, deep clone, deep omit
- Framework-agnostic utilities: event emitter, classNames, clear all timeouts
- Parsing and DSLs: text styling parser

### How to use this repository

- Pick a challenge, read its description, and attempt a clean, testable implementation.
- Consider edge cases, time/space complexity, and ergonomics of the API.
- Add unit tests (happy-path, edge, failure) before you refactor.
- Compare your approach with community patterns and iterate.
