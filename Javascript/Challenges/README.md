## 🔎 Why these JavaScript challenges matter

These problems strengthen practical skills across asynchronous JavaScript, promises, functional patterns (debounce, currying, composition), data structures, DOM manipulation, and API performance techniques (caching, retries, circuit breaker). They are ideal for interview prep, daily practice, and building a strong foundation for front-end architecture.

### Key topics covered

- Asynchronous control flow: `fetch` timeout, circuit breaker, async batching
- Promise utilities: promisify, sequential queues, concurrent execution limits
- Functional utilities: debounce, currying, piping/composition
- Data structures & algorithms: deep omit, object getters, in-memory search
- DOM manipulation: class hierarchy selection, JSON to HTML conversion
- Framework-agnostic utilities: event emitter, classNames, clear all timeouts, proxy patterns
- Parsing and DSLs: text styling parser
- Advanced patterns: chainable APIs, throttled batch processing

### How to use this repository

- Pick a challenge, read its description, and attempt a clean, testable implementation.
- Consider edge cases, time/space complexity, and ergonomics of the API.
- Add unit tests (happy-path, edge, failure) before you refactor.
- Compare your approach with community patterns and iterate.
