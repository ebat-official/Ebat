## 🔎 Why these JavaScript questions matter

These questions focus on execution order, hoisting, coercion rules, prototype behavior, function contexts, and edge cases. Practicing them helps you articulate “what happens under the hood,” a key differentiator in technical interviews.

### Key topics covered

- Execution model: call stack, event loop, microtasks vs macrotasks
- Coercion and operators: unary plus, equality, toString/valueOf
- Closures, scope, hoisting, and IIFEs
- Arrays and objects: detection, iteration, and mutation semantics
- Prototypes and method overriding

### How to use this repository

- Attempt each question, explain the output first, then verify by running code.
- Write a minimal reproduction snippet and annotate key steps (coercion, hoisting, evaluation order).
- Generalize the concept to related patterns you may encounter in interviews.
